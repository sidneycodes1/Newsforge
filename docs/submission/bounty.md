## What NewsForge Does
NewsForge is an autonomous AI content pipeline that runs every 30 minutes without human input. It fetches live news, writes an article, generates a cover image, and produces an audio summary using ACE Data Cloud APIs for every step.

## ACE Services Used (4 total — 3 required)
1. ACE Serp Google API — live news fetching
2. ACE Chat/Completions API — article generation
3. ACE Image Generation API — cover image creation
4. ACE TTS API — audio summary generation
